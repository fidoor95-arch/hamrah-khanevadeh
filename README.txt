همراه خانواده — بسته آماده انتشار نسخه وب روی Vercel

محتویات:
- index.html: نسخه وب موجود برنامه (کد اصلی حفظ شده و فقط نام فایل به index.html تغییر کرده است)
- vercel.json: تنظیم ساده میزبانی فایل استاتیک

روش انتشار پیشنهادی:
1. این ZIP را از حالت فشرده خارج کنید.
2. وارد https://vercel.com/new شوید و وارد حساب شوید.
3. بهترین روش پایدار: پوشه را به یک مخزن GitHub بارگذاری کنید، سپس در Vercel گزینه Import Git Repository را انتخاب کنید.
4. چون این نسخه یک فایل HTML مستقل است، نیازی به Build Command یا Output Directory خاصی نیست؛ اگر Vercel پرسید، Framework Preset را روی Other بگذارید و Build Command را خالی بگذارید.
5. پس از انتشار، برنامه را باز کنید و ورود/ساخت خانواده/کد دعوت/همگام‌سازی با دو مرورگر یا دو دستگاه را آزمایش کنید.

نکته امنیتی:
کلید sb_publishable در فرانت‌اند قابل استفاده است، اما هرگز کلید service_role یا secret را در HTML قرار ندهید. امنیت داده‌ها به تنظیمات Auth و RLS در Supabase وابسته است.

توجه:
این بسته برای میزبانی فایل وب است و عملکرد واقعی ورود و همگام‌سازی را تضمین نمی‌کند؛ آن بخش باید پس از انتشار آزمایش شود.
